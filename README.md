# Installation

### Step 1

Install **01cedric COD Updater** and the required **COD files**.

### Step 2

Drag and drop the `MAG_MENU_MW` files into your **Mw mods folder**.

### Step 3

Launch MW go in mods option, enable MAG MENU MW and start a **Private Match** to use the menu.
